## 主版本

**【产品描述】**

「词元新学」是面向大学生的本地优先自主学习智能体平台，致力于打造一种由 Token（词元）驱动的新型自主学习方式：以大语言模型为推理引擎、以 Token 预算为任务调度单位，平台将学生"想学会一样东西"的意图转化为 AI 可自主执行的任务——检索、阅读、总结、出题、批改、安排复习全部由智能体完成，学生只做决策与思考。

平台围绕完整学习闭环构建六大环节：**文档精读 → 深度调研 → 资料沉淀 → 练习出题 → 智能判分 → 间隔复习**。核心差异在最后两环：系统基于学习资料自动出题、判分，并按 Leitner 五盒遗忘曲线算法安排复习、到期自动回炉——把"读过的"变成"会回来的记忆"，而不只是留在聊天记录里。

深度调研能力已通过真实场景验证：对比四所高校计算机专硕招生信息这类原本需人工翻查数十个官网、下载多份 PDF 的任务，AI 自主规划检索与阅读路径，实测约 3 分钟完成 39 次检索与 27 次网页/文档解析，产出含 64 个来源链接的十列对比报告；可解析研招网异步目录与 PDF 附件，多来源冲突时显式标红并列、查不到如实标注"未获取到"。

平台化是关键设计：通过"目标轨道"机制适配考研、考公、求职等学习场景，新场景仅需一份配置文件而非新代码；每个数字附来源、Token 预算透明可控。产品采用本地优先架构，学习数据全部保存在本机，具备 SSRF 防护、文件围栏与危险操作确认机制，契合高校数据安全要求。工程上已完成约 2.7 万行 Python、9 千行前端与近千个自动化测试用例。

**【用户群体】**

全国在校大学生（约 4700 万人）。首批切入考研备考场景（2026 年报名 343 万人）——这是自主学习需求最刚性、信息最不对称的细分；随后覆盖考公、求职与日常课程学习、科研文献精读等场景。

**【项目愿景】**

让每一位普通学生都拥有数据不出本机的"私人学习研究员"：把跨站比对信息、消化资料、对抗遗忘的重复劳动交给由 Token 驱动的智能体，把学生的精力还给真正的理解、决策与创造。

**【竞争对手】**

Kimi、豆包、NotebookLM 等通用 AI 助手止步于"读与问"，无知识沉淀与复习机制；传统学习平台是"内容库 + 人工维护"，无法个性化执行。本项目以完整学习闭环、场景平台化扩展与本地隐私优先形成差异；壁垒在数据解析管线、Token 预算调度与本地知识资产，不依赖单一模型供应商。

## 精简版（约 330 字，表格拥挤时用）

「词元新学」是面向大学生的本地优先自主学习智能体平台，致力于打造由 Token 驱动的新型自主学习方式：AI 以 Token 预算自主执行检索、阅读、总结、出题、批改与复习安排，学生只做决策。平台围绕"精读→调研→沉淀→出题→判分→间隔复习"构建完整学习闭环，按 Leitner 遗忘曲线安排复习回炉；"目标轨道"机制以配置文件适配考研、考公、求职等场景，新场景零代码扩展。数据全部保存在本机，具备 SSRF 防护与文件围栏，契合高校数据安全要求。区别于 Kimi/豆包/NotebookLM"问答即止"的通用助手，本项目以学习闭环、场景平台化、数据本地化形成差异。已完成 2.7 万行 Python、9 千行前端与近千个测试用例，实测四校择校调研 3 分钟产出含 64 个来源链接的对比报告，具备完整演示条件。
